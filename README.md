# SYNQEVRA Agents

Working starter projects from [SYNQEVRA Solutions](https://github.com/SYNQEVRASolutions). Each one runs on its own with no cloud account, and each one solves a specific operational problem rather than demoing a framework.

We build these for clients against the equipment and tools they already run. The public repos are the same patterns, stripped to the parts that matter.

## Projects

| Project | What it does | Stack | Status |
|---|---|---|---|
| [ai-ups-monitor-agent](https://github.com/SYNQEVRASolutions/ai-ups-monitor-agent) | Reads UPS telemetry over SNMP, learns a per-site baseline, alerts with what failed, what is affected, urgency and next action | Python, SNMP | v1.0.0 |
| [compressor-health-agent](./agents/compressor-health-agent) | Air compressor and dryer monitoring: drift in discharge temperature, oil pressure, load cycles and dew point turned into one actionable alert | Modbus, OPC UA, MQTT | listing |

## What we build for clients

1. **AI agents and agentic workflows** - custom built, deployed and monitored, not a prototype.
2. **Industrial and data center AI monitoring** - UPS, compressor, HVAC, generator and PLC telemetry turned into alerts that carry an action.
3. **Predictive maintenance** - per-asset baselines instead of fixed thresholds, so slow degradation is caught before it trips.
4. **Chatbots** - support and lead capture on WhatsApp and web.
5. **AI automation** - connecting existing tools so manual work disappears.
6. **Custom software and MVPs**.

## How an engagement works

1. A short call about the equipment, the existing tools and what actually breaks.
2. A scoped build with a fixed deliverable and a delivery date.
3. Deployment into your environment, then monitoring and tuning.
